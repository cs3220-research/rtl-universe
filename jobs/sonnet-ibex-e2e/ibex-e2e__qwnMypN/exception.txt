## Your Task

Implement the stripped files so all four e2e software simulation tests pass:

1. **`hello_test`** — basic I/O, timer interrupt, WFI (`puts`, `puthex`, timer)
2. **`dit_test`** — data-independent timing (DIT) feature of the CSR
3. **`dummy_instr_test`** — dummy instruction insertion security feature
4. **`pmp_smoke_test`** — Physical Memory Protection region enforcement

Each test is compiled from C to a `.vmem` file, loaded into the Ibex
simple-system simulator, and run. A test passes if the simulator exits with
code 0. Test programs use `sim_halt()` to end the simulation.

## Scoring

Reward is **proportional**: `passed_tests / 4` (float in `[0, 1]`).

Each of the 4 SW simulation tests is worth 1 point. Partial credit is awarded.

## Useful Commands

```bash
# Build the simple-system Verilator simulator
fusesoc --cores-root=. run --target=sim --setup --build lowrisc:ibex:ibex_simple_system

# Compile a software test binary
cd examples/sw/simple_system/hello_test && make && cd /app

# Run a software test on the simulator
build/lowrisc_ibex_ibex_simple_system_0/sim-verilator/Vibex_simple_system \
    --raminit=examples/sw/simple_system/hello_test/hello_test.vmem

# Compile all SW tests
for t in hello_test dit_test dummy_instr_test pmp_smoke_test; do
    (cd examples/sw/simple_system/$t && make)
done

# Run all SW tests
SIM=build/lowrisc_ibex_ibex_simple_system_0/sim-verilator/Vibex_simple_system
for t in hello_test dit_test dummy_instr_test pmp_smoke_test; do
    echo "=== $t ===" && "$SIM" --raminit="examples/sw/simple_system/$t/${t}.vmem" && echo PASSED || echo FAILED
done
```
